Privacy Policy

Last updated: April 17, 2026

Algo Lens is a bring-your-own-key extension. We don't run servers, and we don't collect, transmit, or sell any personal data. This page explains exactly what stays on your device and what leaves it.

What stays on your device

  • Your Gemini API key (stored via chrome.storage.local).
  • Your model and UI preferences (streaming toggle, auto-analyze, etc.).
  • Up to 25 most-recent analyses (problem title, your code, Gemini's response, timestamp).
  • An optional manual code snippet you paste into the fallback box.

You can wipe all of it via Settings → Clear history, or by removing the extension.

What leaves your device — and where it goes

When you click Analyze, the following is sent directly to Google's Gemini API (generativelanguage.googleapis.com) authenticated with your own key:

  • The LeetCode problem title, URL, and description scraped from the current tab.
  • The code you wrote in the LeetCode editor (or pasted in the manual box).
  • The detected language.

Gemini's handling of that data is governed by Google's Gemini API terms and privacy policy. We never see it — the request goes browser → Google, end of story.

What we don't do

  • No analytics, telemetry, or crash reporting.
  • No remote code execution — no eval, no dynamic script loading.
  • No ad networks, no third-party SDKs.
  • No background scraping: we only read the page when you explicitly click Analyze.

Permissions, explained

  • activeTab — read the current LeetCode tab when you invoke Analyze.
  • storage — save your API key, preferences, and history locally.
  • sidePanel — render the Algo Lens panel next to LeetCode.
  • scripting — inject the floating Analyze button on problem pages.
  • contextMenus — add the "Analyze snippet" right-click item.
  • https://leetcode.com/* — to scrape the problem you're looking at.
  • https://generativelanguage.googleapis.com/* — to call Gemini with your key.
